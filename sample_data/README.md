# Sample Dataset

## File and settings

- File: `spherical_ag2se.jpg`
- Example type: Spherical Ag2Se nanoparticles
- Detection mode: `Spherical dot`
- Scale-bar length: `50 nm`
- Scale-bar color: `black`

## Usage

1. Start NC-TEM Analyzer.
2. Upload `spherical_ag2se.jpg`.
3. Select `Spherical dot`.
4. Enter `50` for the scale-bar length in nanometers.
5. Select `black` as the scale-bar color.
6. Click `Run Auto-Detect`.
7. Inspect the detected-particle overlay.
8. Exclude false or incorrectly detected particles. Manually adjust the size or
   position only for detections that require correction.
9. Review the corrected overlay and the updated size histogram.
10. Export the final results if needed.

The image is provided solely as a minimal example for testing the software
workflow. Detection counts and size statistics may vary when the analysis
settings or manual corrections are changed.
